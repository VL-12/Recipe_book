ROADMAP

## Сейчас: 
MVP версия приложения
- Пользователь может просматривать список рецептов.
- Пользователь может добавить новый рецепт.
- Пользователь может изменить рецепт.
- Пользователь может удалить рецепт.

## Потом
- Можно искать рецепты
- Можно добавлять категории
- Можно загружать фото к рецепту

- Возможность делиться рецептами
