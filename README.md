# Название проекта

Recipe book

📝 Описание

Приложение для записи и сохранения своих рецептов 

⚡ Основной функционал
- Отображение записанных пользователем рецептов
- Добавление нового рецепта 
- Редактирование уже существующего рецепта
- Удаление рецепта 
- Добавление фотогравий ингридиентов и готовых блюд 

🛠 Стек технологий
- Python
- Flask 
- Sqlalchemy 
- Alembic 
- Bootstrap
